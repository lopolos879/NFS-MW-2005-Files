ИНСТРУКЦИЯ ПО УСТАНОВКЕ:

1. Перейдите по ссылке ниже: 
[https://drive.google.com/file/d/1qMquXkduMftCahYxieL8MHh2HWgrFHQU/view?usp=sharing](https://drive.google.com/file/d/1qMquXkduMftCahYxieL8MHh2HWgrFHQU/view?usp=sharing)

2. Установите *NFS MW (2005) Files.zip*.

3. Распакуйте содержимое в свободную папку.

4. Найдите файл "*AutoRun.exe*" в папке "*Need For Speed Most Wanted (2005)*" и запустите его.

5. Введите серийный ключ из папки "*NFS MW (2005) Serial Key*".

6. Дождитесь установки и запустите "*nfsmwpatch1.3.exe* из папки *nfsmwpatch1.3*".

7. После установки "*nfsmwpatch1.3.exe*" найдите в папке "*No-CD Fix*" файл "*speed.exe*", после чего
замените файл "*speed.exe*" в папке с установленной ИГРОЙ на "*speed.exe*" из папки "*No-CD Fix*".

8. Установка и настройка игры завершена, запустить игру можно через файл "*speed.exe*" в папке с ИГРОЙ.
